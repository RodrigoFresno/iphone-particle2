IPHONE PARTICLES — APP WEB INSTALÁVEL

O QUE É
Este projeto é um PWA: um aplicativo web que pode ser adicionado à tela inicial do iPhone e aberto em modo independente, sem a barra do navegador. Também guarda os arquivos essenciais para uso offline depois da primeira visita.

COMO PUBLICAR GRATUITAMENTE COM GITHUB PAGES
1. No computador, entre em github.com e crie um repositório público chamado iphone-particles.
2. Extraia este ZIP e envie TODOS os arquivos e a pasta icons para a raiz do repositório (não envie a pasta externa iphone-particles-pwa).
3. No repositório, abra Settings > Pages.
4. Em Build and deployment, escolha Deploy from a branch.
5. Selecione Branch: main e Folder: /(root), depois Save.
6. Aguarde o endereço publicado, normalmente https://SEU-USUARIO.github.io/iphone-particles/.

COMO ADICIONAR PELO CHROME NO IPHONE
1. Abra o endereço publicado no Chrome do iPhone.
2. Toque em Compartilhar (ícone de compartilhar ao lado da barra de endereço).
3. Escolha Add to Home Screen / Adicionar à Tela de Início.
4. Confirme o nome Particles e toque em Add / Adicionar.
5. Abra pelo novo ícone na tela inicial.

IMPORTANTE
- É necessário publicar em HTTPS para instalação e cache offline confiáveis.
- O projeto não é um aplicativo nativo da App Store; é um PWA.
- O Chrome para iOS oferece a opção de adicionar à tela inicial. O iOS decide a apresentação final do web app.
- Para atualizar o app, publique os novos arquivos e reabra o ícone com conexão à internet.
